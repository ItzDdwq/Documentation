## Создание Списка
- [Вернуться в начало](#Lists)

``` csharp
// Пустой список
List<int> list1 = new List<int>();

// С знаечниями
List<int> list2 = new List<int>() {1, 2, 3, 4, 5};

// Из другой коллекции
int[] array = {1, 2, 3};
List<int> list3 = new List<int>(array);

// С ёмкостью для оптимизации
List<int> list4 = new List<int>(100);
```
