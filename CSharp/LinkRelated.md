## String
- [Вернуться в начало](#Ссылочные-переменные)

Это строка которая хранит данные в двойных ковычках (" ").

[См. Методы строки](String.md)

``` csharp
string name = "Ddwq";
string hello = "Hello";
```

## Object
- [Вернуться в начало](#Ссылочные-переменные)

Любой тип наследуется от **object**.

``` csharp
object a = 123;
object b = "Привет";

int c = (int)a + 5;
```

---
---


## Dynamic
- [Вернуться в начало](#Ссылочные-переменные)

Это тип который выключает проверку компилятора.

``` csharp
dynamic a = 123;
dynamic b = "Привет";

int c = a + 5;
int d = b + 5; 
```

## Var
- [Вернуться в начало](#Значимые-переменные)

Тип данных который сам узнает к какому типу относятся данные.

``` csharp
var a = "Hello"; // string
```
