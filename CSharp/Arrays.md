## Обычный Массив
- [Вернуться в начало](#Массивы)

``` csharp
int[] numbers = {1,2,3,4};
```
#### Действия с массивом
- [Вернуться в начало](#Массивы)

Изменение ячейки
``` csharp
numbers[0] = 2;
```
Получить данные из ячейки
```csharp
Console.WriteLine(numbers[1]);
```

## Матрица
- [Вернуться в начало](#Массивы)

``` csharp
int[,] matrix = // new int[3, 3] - не обязательно вводить
            {
                {1, 2, 3},
                {4, 5, 6},
                {7, 8, 9}
            };
```
#### Действия с массивом
- [Вернуться в начало](#Массивы)

Изменение ячейки
``` csharp
matrix[0][0] = 2;
```
Получить данные из ячейки
```csharp
Console.WriteLine(numbers[0][0]);
```

## Массив с массивами
- [Вернуться в начало](#Массивы)

``` csharp
int[][] table = new int[][]
            {
                new int[] { 1, 2 },
                new int[] { 3, 4, 5, 6 },
                new int[] { 7, 8, 9 }
            };
```
#### Действия с массивом
- [Вернуться в начало](#Массивы)

Изменение массива
``` csharp
table[0][1] = 4;
```
Получить данные из массива
```csharp
Console.WriteLine(table[1][1]);
```
