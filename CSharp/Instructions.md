## If-Else
- [Вернуться в начало](#Инструкции)

Условный оператор который выполняет блок кода если условие верно.

``` csharp
int a = 5;
if(a == 5){
  // Логка
} else if(a >= 10){
  // Логика
} else{
  // Выполнится если все условия False
}
```
